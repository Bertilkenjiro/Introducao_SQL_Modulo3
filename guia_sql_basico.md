# 🧠 Guia Rápido – Comandos SQL Básicos

| Comando | Descrição | Exemplo |
|----------|------------|----------|
| SELECT | Retorna dados de uma tabela | `SELECT * FROM tabela` |
| COUNT() | Conta registros | `SELECT COUNT(*) FROM tabela` |
| DISTINCT | Mostra valores únicos | `SELECT DISTINCT coluna FROM tabela` |
| TOP(N) | Limita número de linhas | `SELECT TOP(10) * FROM tabela` |
| AS | Renomeia colunas | `SELECT coluna AS 'NovoNome'` |
